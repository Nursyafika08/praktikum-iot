Repository ini berisi kumpulan program dan hasil pengerjaan Praktikum Internet of Things (IoT) Modul 1 sampai Modul 5.

## Daftar Modul

### Modul 1 - Monitoring dan Pengendalian Suhu
Mempelajari pembacaan sensor DHT11, perhitungan rata-rata, pengendalian relay, dan sistem histeresis.

### Modul 2 - Koneksi WiFi ESP8266
Mempelajari mode WiFi Station (STA), Access Point (AP), reconnect, serta kombinasi AP dan STA.

### Modul 3 - Komunikasi HTTP dan MQTT
Mempelajari pengiriman dan penerimaan data menggunakan protokol HTTP dan MQTT dengan format JSON.

### Modul 4 - Komunikasi Dua Arah MQTT
Mempelajari mekanisme publish dan subscribe untuk pertukaran data serta pengendalian perangkat melalui MQTT.

### Modul 5 - Pengolahan dan Analisis Data
Mempelajari moving average, analisis statistik, penyimpanan data CSV, deteksi anomali, dan visualisasi menggunakan Python.
