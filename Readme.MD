# PRAKTIKUM INTERNET OF THINGS (IoT)

Repository ini berisi kumpulan program dan laporan praktikum Internet of Things (IoT) Modul 1 sampai Modul 5.

## Daftar Modul

### Modul 1 - Monitoring dan Pengendalian Suhu
Mempelajari pembacaan sensor DHT11, perhitungan rata-rata, pengendalian relay, dan sistem histeresis.

### Modul 2 - Koneksi WiFi ESP8266
Mempelajari mode WiFi Station (STA), Access Point (AP), reconnect, serta kombinasi AP dan STA.

### Modul 3 - Protokol Komunikasi IoT
Mempelajari komunikasi HTTP dan MQTT menggunakan format JSON.

### Modul 4 - Komunikasi dan Pertukaran Data
Mempelajari komunikasi dua arah menggunakan MQTT dengan mekanisme publish dan subscribe untuk mengendalikan aktuator.

### Modul 5 - Pengolahan dan Analisis Data
Mempelajari moving average, analisis statistik, akuisisi data MQTT, penyimpanan CSV, deteksi anomali, dan visualisasi menggunakan Python.
